Server Credentials Manager UI

Help

This page explains how to define named connection credentials, assign them to client nodes, and populate the OpAMP ServerToAgent connection settings payload.

Connection Definition Panel

  • Name: Enter the named connection definition that will be stored and reused.
  • Save: Persists the current definition and validates the payload before it is stored.
  • Defined connections table: Shows every saved connection definition.
  • Row selection: Selecting any row loads that definition into the Connection settings panel.
  • Apply: Queues the selected connection for every assigned client node, or writes a fallback JSON log when the provider endpoint is unavailable.
  • Remove: Use the minus button on a row to delete a connection definition when it is not assigned to any clients.
  • Assign: Opens the assignment dialog for the selected connection definition.

Defined Connections Filters

The defined connections table includes an inline filter row directly beneath the column headings.

  • Connection name filter: Uses case-insensitive substring matching against the saved connection name.
  • Assigned client nodes filter: Shows any connection assigned to a client node whose name contains the entered text.
  • Combined filtering: When both filters are populated, a row must match both conditions to remain visible.
  • Immediate updates: Filtering updates the table immediately with no separate apply action.

Connection Settings Panel

  • Connection tabs: Use the tabs to switch between opamp, own_metrics, own_traces, own_logs, and other connection sections.
  • Per-tab values: Each tab keeps its own values, and switching tabs restores the values previously entered for that section.
  • Other connection name: The extra connection name field is only used on the Other connection tab.
  • Enable this connection: Controls the enabled flag for the currently selected connection section.
  • Copy from: Copies the field values from another named tab into the current tab.

Certificates, Keys, and TLS

  • File selectors: Use the file picker controls to upload certificate, key, and CA files.
  • Stored references: After upload, the UI stores and shows the backend file reference rather than the browser-local file path.
  • TLS versions: Minimum and maximum TLS values come from the configured TLS versions document used by the backend.
  • File picker reset: Changing tabs or connection definitions resets the browser file selectors while preserving the saved backend references shown in the text fields.

Assignment Dialog

  • Available client nodes: The left list shows nodes that can be assigned to the current connection.
  • Assigned client nodes: The right list shows nodes already assigned to the current connection.
  • Arrow buttons: Move selected client nodes into or out of the assigned list.
  • Save: Writes the many-to-one client-to-connection mapping document.
  • Add Test Clients: Seeds 20 mock clients for standalone testing when a provider client list is not available.

Validation Rules on Save

  • Endpoints: destination_endpoint and proxy.url must be valid absolute http:// or https:// addresses when provided.
  • JSON fields: headers, other_settings, and proxy.connect_headers must be valid JSON objects.
  • Connection names: Connection names and other_connections keys must not be blank.
  • User feedback: Validation failures are returned during save so incorrect payloads can be corrected before storage.

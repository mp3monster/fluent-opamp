_meta Comment Help

How editor-only comments are stored for service blocks, plugins, processors, labels, workers, and fields.

What `_meta` is for

`_meta` stores editor-only comment information alongside the object it belongs to. The comments stay attached to the object while you edit, move, save, reload, validate, and render configurations.

Supported Structure

{
  "_meta": {
    "comment_lines": [
      "Comment line 1",
      "Comment line 2"
    ],
    "field_comment_lines": {
      "port": [
        "Comment for a single field"
      ]
    }
  }
}

`comment_lines` applies to the whole object. `field_comment_lines` applies to specific fields on that object.

How Comments Render

When comment rendering is enabled, each line is emitted as its own comment line in the generated Fluent Bit YAML. Native Fluentd configuration rendering ignores `_meta`, so editor comments do not leak into the runtime config unless the renderer explicitly supports them.

UI Behavior

The notepad button opens or closes the comment editor for the related object or field. The question mark button opens this bundled help page in a new tab and shows a tooltip when you hover over it.
